# Launchpad Creators website

The website for [launchpadcreators.com](https://launchpadcreators.com), built with Astro and Tailwind.

- **Preview:** https://launchpadcreators.github.io/lpc-website/ (updates automatically from `main`)
- **Rules for making changes:** [CLAUDE.md](CLAUDE.md)
- **Update history and current status:** [CHANGELOG.md](CHANGELOG.md)

```sh
npm install
npm run dev     # http://localhost:4321
npm run build   # outputs dist/
```
